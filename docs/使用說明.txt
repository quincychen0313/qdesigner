qDesinger — 擷取工具完整網頁版（2026-10-16）

入口：左側工具列最上方的擷取工具圖示（兩個功能共用一格）。
短按：開啟上次選用的功能。
長按約 0.35 秒：展開 Grab Text／Magic Grab 選單。放開後點選，或按住拖到選項上再放開。
選用後圖示跟著切換。按 Esc 或點選單外取消。先開啟圖片才能使用。
也可由編輯 → 擷取工具（Edit → Grab tools）開啟。

擷取文字 Grab Text：
1. 開啟圖片，在圖層面板選取圖片圖層。
2. 選擷取文字，選擇辨識語言，再按「辨識文字」。
3. 校對文字，勾選要擷取的行，調整文字顏色，再按「套用擷取」。
4. 每行建立一個可編輯文字圖層；使用文字工具修改，移動工具調整位置。
5. 「修補原本的位置」預設開啟；關閉時會清除原區域並留下透明背景。
辨識支援繁體中文＋英文、英文、簡體中文＋英文、日文、韓文。
字型、字距、字級並非精確重建，需要依原圖手動校正。

智慧擷取 Magic Grab：
1. 開啟圖片，選取圖片圖層，選智慧擷取。
2. 自動偵測主體，或先用物件選取／快速選取工具圈選，再勾「使用目前的選取範圍」。
3. 套用後，主體成為獨立圖層，可移動、縮放；原位置預設以鄰近背景修補。
採用本機的顏色與邊緣分析、背景修補；複雜背景、半透明物件和髮絲可能需要手動修整。修補較大範圍時需等待處理完成。

原圖保留成隱藏圖層；一次還原可復原整個擷取操作。
工具限最高 400 萬像素、一般可見像素圖層；帶遮色片、效果、鎖定或特殊混合的圖層請先合併副本。
文字辨識上限 200 行。圖片在瀏覽器本機處理，不會上傳辨識服務，不需 API 金鑰。
網站必須使用 HTTP/HTTPS 開啟，不能直接雙擊 HTML。首次使用需載入辨識資料與字型。
本包保留之前的中日韓介面字型修正、分段載入、Actions 與 PDF 功能。

更新時必須覆蓋完整內容，尤其是新版 JS、所有 BIN、ocr 與 fonts 資料夾，不能只替換首頁。
